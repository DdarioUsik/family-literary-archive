ПРИВАТНОЕ ОБЛАЧНОЕ ХРАНИЛИЩЕ

Материалы хранятся в закрытом GitHub-архиве

Для загрузки откройте нужную подборку и войдите в GitHub.

Файлы загружаются на GitHub напрямую и не попадают в публичную часть сайта. Доступ есть у владельца приватного репозитория и приглашённых участников. Чтобы родственник загружал материалы самостоятельно, владелец архива должен добавить его GitHub-аккаунт. Через браузер GitHub принимает до 25 MiB на файл; более крупные сканы потребуют загрузки через Git LFS.

i

Приватный архив и публичное исследование разделены.

Ссылки «Загрузить на GitHub» открывают приватные папки, доступные вашему аккаунту и приглашённым участникам. Публичный сайт не получает копию файлов. Загрузка через кнопку «Сохранить только в браузере» остаётся на этом устройстве и видна только в текущем браузере. GitHub сохраняет историю изменений файлов; удаление из текущей папки само по себе не стирает прежние версии из истории репозитория.
