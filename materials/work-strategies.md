# Индивидуальные стратегии

Каждая карточка относится к отдельной записи каталога. Стратегии — условные гипотезы, основанные на библиографии и публичных профилях партнёров; полный корпус произведений не прочитан. Сюжеты по названиям не реконструировались.

Географии — приоритет проверки/поиска, а не подтверждённый спрос. Партнёры подтвердили своим публичным каталогом профиль деятельности; готовность приобрести конкретные права не установлена. Указанные тесты — будущие действия после проверки права на раскрытие и отдельного решения об обращениях.
